
# Java Generics

A hands-on learning repository dedicated to understanding and mastering Java
Generics through practical examples, exercises, experiments, and technical notes.

## Objectives

The primary objective of this repository is to develop a strong conceptual
and practical understanding of Java Generics and their applications in
modern Java development.

This repository also serves as a foundation for learning:

- Java Collections Framework
- Data Structures and Algorithms (DSA)
- Java Streams API
- Type-safe API design
- Reusable software components
- Professional Java development practices

## Learning Methodology

The following approach will be used for each concept:

1. Understand the problem that the concept addresses.
2. Study the underlying theory.
3. Predict the behavior of Java code before executing it.
4. Implement practical examples.
5. Experiment with valid and invalid scenarios.
6. Analyze compiler errors and runtime behavior.
7. Document important observations in Markdown.
8. Complete independent coding exercises.
9. Commit meaningful changes to Git.

## Building the Project

Compile the project:

```bash
mvn clean compile
```

Build the project:

```bash
mvn clean package
```

Individual examples can be executed through IntelliJ IDEA.

## Engineering Conventions

This repository follows the following engineering conventions:

- UTF-8 character encoding
- LF line endings by default
- CRLF for Windows-specific batch and command scripts
- No unnecessary trailing whitespace
- A final newline in every text file
- Four-space indentation for Java
- Consistent and meaningful naming conventions
- Small, meaningful Git commits
- IDE-independent project organization
- Markdown-first documentation
- No generated build artifacts in version control
